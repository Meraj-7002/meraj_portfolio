# meraj_portfolio

Portfolio of Mohd Meraj Ansari, Full-Stack Engineer.

Plain HTML, CSS and JS. No framework and no build step.

- `index.html`: all content
- `styles.css`: design tokens (light and dark, following the system setting) and layout
- `main.js`: `CONFIG` (email, LinkedIn, GitHub, resume) at the top, plus the contact form. Empty values are hidden from the page.

Run locally: open `index.html`, or run `npx serve .`

Deploy: GitHub Pages (Settings → Pages → branch `main`, root) or Vercel, no build settings needed.
